## Como desenvolvo

- **Arquitetura com propósito:** Clean Architecture, SOLID, separação de responsabilidades,
  CQRS e handlers quando ajudam a organizar os casos de uso. A complexidade acompanha a necessidade do projeto.
- **Segurança desde a API:** autenticação JWT, refresh token rotativo, sessões persistidas,
  autorização por permissões, rate limiting e isolamento de dados entre organizações.
- **Integrações confiáveis:** eventos de integração, Transactional Outbox, Inbox,
  consumidores idempotentes, retries e tratamento de falhas.
- **Consistência dos dados:** validações de negócio, prevenção de duplicidades, transações,
  concorrência otimista, migrations e procedimentos de backup e restauração.
- **Contratos e experiência de uso:** respostas HTTP coerentes, ProblemDetails,
  paginação, validações de formulário e interfaces responsivas.
- **Qualidade e operação:** testes dos fluxos críticos, revisão por pull requests,
  análise de dependências e rastreabilidade com logs, métricas e traces.
